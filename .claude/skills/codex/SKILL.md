# Codex

Codex CLI を非対話モード（`codex exec`）で実行し、出力をそのまま端末に流す。
MCP 経由と違い、進捗が見えるので待ち時間や中断判断がしやすい。

## 実行コマンド

```bash
codex exec --sandbox read-only --cd <project_directory> "<依頼内容>"
```

- `--sandbox read-only`: 読み取り専用。Codex にファイルを書き換えさせない
- `--cd <dir>`: 対象のプロジェクトディレクトリ（通常はカレントディレクトリ）
- `"<依頼内容>"`: 日本語で書いてよい
- Git リポジトリ外で実行する場合は `--skip-git-repo-check` を付ける
- 長く出力される場合は `-o <file>` で最終メッセージだけファイルにも保存できる

実行には時間がかかることがあるので、Bash ツールの `timeout` を長め（例: 600000）にする。

## プロンプトのルール

Codex は途中で質問して止まることがあるため、依頼文の末尾に必ず次を付ける:

> 確認や質問は不要です。具体的な提案・修正案・コード例まで出力してください。

## 手順

1. ユーザーの依頼内容を把握する
2. 対象ディレクトリを決める（指定がなければカレントディレクトリ）
3. 依頼文を組み立て、末尾に上記の「質問不要」の一文を付ける
4. `codex exec` を実行する
5. Codex の回答を要約してユーザーに報告する。Codex の指摘は鵜呑みにせず、
   コードを確認したうえで妥当かどうかの所見も添える

## 依頼文の例

- コードレビュー:
  `src/ 以下の変更をレビューしてください。バグ、エッジケース、可読性の問題を重要度順に挙げてください。確認や質問は不要です。具体的な提案・修正案・コード例まで出力してください。`
- バグ調査:
  `ログイン後にセッションが切れる不具合の原因を調査してください。関連しそうなファイルと原因の仮説、修正案を示してください。確認や質問は不要です。具体的な提案・修正案・コード例まで出力してください。`
- 設計相談:
  `このプロジェクトのアーキテクチャを分析し、責務の分離や依存関係の問題点と改善案を示してください。確認や質問は不要です。具体的な提案・修正案・コード例まで出力してください。`
- 文章レビュー:
  `README.md の文章をレビューし、分かりにくい箇所と書き換え案を示してください。確認や質問は不要です。具体的な提案・修正案・コード例まで出力してください。`

## 画像生成

Codex の画像生成ツール（`image_generation` 機能）でイラストなどを作れる。
ファイルを保存させる必要があるので、レビュー用の `read-only` ではなく、
出力先フォルダだけ書き込める `workspace-write` で実行する。

```bash
mkdir -p <出力先ディレクトリ>
codex exec --skip-git-repo-check --sandbox workspace-write --cd <出力先ディレクトリ> \
  "画像生成ツールを使って、<作りたい画像の説明>を1枚生成し、このディレクトリに <ファイル名>.png として保存してください。確認や質問は不要です。"
```

- 出力先は、ユーザーの指定がなければスクラッチパッド内の専用フォルダにする。
  プロジェクトに置く指定があった場合だけ、そのディレクトリを使う
- `--cd` で指定したフォルダの外には書き込めない。プロジェクト全体を `--cd` にしない
- 生成画像は `~/.codex/generated_images/` にも残る。保存に失敗したときはここから探す
- 画像生成は数分かかることがあるので、Bash ツールの `timeout` を長め（例: 600000）にする

### 手順

1. 作りたい画像の内容・枚数・ファイル名を把握する（指定がなければ適当に決める）
2. 出力先フォルダを作り、上記コマンドを実行する
3. 生成された画像を Read で確認し、依頼どおりか見る
4. SendUserFile で画像をユーザーに表示し、保存場所を伝える
